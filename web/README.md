# 掌上题库 Safari 版

## 在 iPhone 上使用

1. 联网用 Safari 打开网页的 HTTPS 地址，等页面显示「已可离线使用」。
2. 点 Safari 的「分享」→「添加到主屏幕」→「添加」。如果看到「作为网页 App 打开」开关，请保持开启。这个过程无需安装 IPA 或签名。
3. 从主屏幕图标第一次打开时，请保持联网，再等页面显示「已可离线使用」。之后可以断网打开、导入本机文件、继续刷题或复习单词。
4. 把 Word（`.docx`）或 Excel（`.xlsx`、`.xls`）题库保存到 iPhone 的「文件」App。打开掌上题库，点「导入题库」选择文件。想断网导入 iCloud Drive 中的文件，先把文件下载到本机。

## 背单词

- 首页点「背单词」，用「体验词库」翻卡。显示释义后点「记住了」或「忘记了」，到期词优先复习。
- 点「导入生词本」，在「文件」里选择 Excel（XLSX、XLS）或 UTF-8 的 CSV、TXT、TSV。前四列依次是单词、释义、音标和例句，后两列可留空。Excel 读取第一个工作表，TXT 可用 Tab 分列，也可以每行只填一个单词。[生词本示例](../templates/生词本示例.csv)
- 「导入格式和词库下载」内有四级、六级和考研词表链接。到 GitHub 文件页下载原始 TXT 再导入。[词表来源](https://github.com/KyleBing/english-vocabulary)
- 联网后可在卡片里展开「问 DeepSeek」，填自己的 API Key，查看单词解析或发送自定义问题。默认不会保存 Key；勾选「在此设备记住 API Key」后，Key 会保存在当前浏览器的本地存储中，供这台设备上的同一浏览器再次使用。能访问这台设备和浏览器的人也可能读取它。取消勾选会删除已保存的 Key，也可以使用清除操作删除。模型和推理等级可单独选择，不受记住 Key 的开关影响。模型为 `deepseek-flash` 或 `deepseek-v4-pro`，推理等级为「关闭」「低」「高」「最高」。只有主动发送时，词条和问题才会提交给 DeepSeek，费用由你的 API 账户承担。[DeepSeek API 文档](https://api-docs.deepseek.com/)

题库、生词本与进度保存在本机。同一网站地址、同一浏览器入口再次打开可接着用。主屏幕网页 App、Safari 标签页和原生 App 可能使用各自的存储，请在打算长期使用的入口导入。清除网站数据、删除网页 App 或更换网站地址后可能需要重新导入，建议保留原始文件。

## 构建与托管

在仓库根目录运行 `python web/build.py`，静态文件会生成到 `web/dist/`。也可以运行 `python web/build.py <输出目录>` 指定一个新目录或空目录。把该目录中的所有文件部署到 HTTPS 站点，网页地址应以 `/` 结尾。可以部署在站点根路径或子路径。

网页首次打开时下载本地文件解析库和页面资源。新版资源下载完整后，浏览器会在旧版页面关闭后切换，题库和进度仍保存在原来的数据库中。更新后如果首页还没有「背单词」，关闭旧版页面和主屏幕网页 App，再联网打开一次。如果离线缓存被系统清理，也可联网重开网页恢复缓存。
